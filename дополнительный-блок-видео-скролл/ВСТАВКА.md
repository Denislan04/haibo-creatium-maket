# Блок «3D-мотор при прокрутке»

Источник идеи: `~/.gemini/antigravity/scratch/haibo-landing/creatium-blocks/02_tech_3d.html` и `js/main.js`. Для Creatium подготовлена отдельная исправленная версия: код разложен по вкладкам HTML, CSS и JS, а видео уже размещено по HTTPS-адресу из исходного блока.

## Вставка в Creatium

1. Добавьте одну HTML-секцию. У секции установите нулевые внутренние отступы и разрешите `overflow: visible`, чтобы работал закреплённый экран.
2. В HTML-компоненте вставьте `HTML.html` во вкладку **HTML**, `CSS.css` — во вкладку **CSS**, `JS.js` — во вкладку **JS**. Теги `<style>` и `<script>` добавлять не надо.
3. Создайте следующие встраивания типа **«Редактируемый текст»**. После сохранения значения меняются через редактор Creatium.

| Имя | Начальный текст |
| --- | --- |

| `tech_scroll_title` | Технология внутри |
| `tech_scroll_lead` | Пять узлов, которые помогают управлять лодкой и удерживать выбранную точку. Листайте страницу, чтобы рассмотреть мотор. |

Этот блок можно поставить вместо обычного раздела «Технология» или рядом с ним. Если заменяете раздел, ссылку меню `#hb-tech` обновите на `#hb-tech-story`.

## Что исправлено по сравнению с Antigravity

- В исходном блоке внутри HTML были смешаны `<style>` и `<script>`, а строки SVG в JS содержали неэкранированные кавычки — такой скрипт может не запуститься. Новая версия использует отдельные вкладки и не требует SVG-строк.
- Старый `main.js` задавал `video.currentTime` на каждом кадре анимации; для MP4 это вызывает серию декодирований и рывки. Новая версия переводит видео к кадру один раз при смене шага.
- Код ограничен текущим HTML-компонентом, проверяет загрузку метаданных видео и не меняет несколько внешних контейнеров страницы.
- Тексты привязаны к тем моментам ролика, где соответствующий узел действительно виден. Неподтверждённые числовые характеристики из черновика убраны.

Проверяйте работу в «Предпросмотре» или на тестовой странице. В монтажном редакторе Creatium прокрутка и видео могут отображаться иначе.
