# Поля для вкладки «Встраивания»

В каждом HTML-компоненте создайте поля только из его раздела. Имя копируйте точно.
Для типа «Редактируемый текст» после сохранения кликните по месту на странице и введите значение из последней колонки.
Картинки загружаются по клику; в контейнеры перетаскиваются штатные компоненты Creatium.

## 04_catalog

Каталог содержит 17 товаров и 146 встраиваний. Для каждого товара доступны фото, категория, название, четыре характеристики и цена; у шести товаров есть прежняя цена. Имена и начальные значения перечислены в [ВСТРАИВАНИЯ_КАТАЛОГ.csv](ВСТРАИВАНИЯ_КАТАЛОГ.csv). Пошаговая настройка — [КАТАЛОГ_БЕЗ_БД.md](КАТАЛОГ_БЕЗ_БД.md).

Три поля заголовка: `cat_kicker`, `cat_title`, `cat_intro` — тип «Редактируемый текст». Поле `cat_form` — тип «Контейнер для компонентов». Остальные имена начинаются с `cat_` и содержат ID товара, например `cat_m_p001_54_title`. Суффикс `_image` означает тип «Загружаемая картинка», остальные товарные поля — «Редактируемый текст».
