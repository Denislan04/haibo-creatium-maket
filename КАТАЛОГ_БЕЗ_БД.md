# Каталог HAIBO без подключения к базе данных

Блок 04 содержит 17 товаров прямо в HTML: 5 моторов и 12 аксессуаров. Каталог открывается и показывает товары без JS. JS нужен только для шести кнопок фильтра. CSS находится только в CSS-вкладке этого же блока.

## Замена текущего блока в Creatium

1. Сделайте копию тестовой страницы или секции каталога.
2. Выберите HTML-компонент старого каталога. В его настройках «Данные» отключите подключение к таблице. Таблица больше не нужна блоку 04.
3. Во вкладке «Исходный код» замените содержимое **HTML** на `блоки/04_catalog.html`, **CSS** на `блоки/04_catalog.css`, **JS** на `блоки/04_catalog.js`. Вставляйте содержимое файлов целиком, без тегов `<style>` и `<script>`.
4. Во вкладке «Встраивания» создайте поля из `ВСТРАИВАНИЯ_КАТАЛОГ.csv`. Имя должно совпасть точно. Поля `_image` — тип «Загружаемая картинка», `cat_form` — «Контейнер для компонентов», остальные — «Редактируемый текст».
5. Введите начальные значения текстов из CSV. Они также вписаны внутрь тегов `<cr-embed>` в HTML для удобства копирования, но документированный способ сохранить их в Creatium — заполнить поля встраиваний. В `cat_form` можно перетащить штатную кнопку или форму; если она уже была, сохраните её.
6. Сохраните и откройте «Предпросмотр». На кнопке «Все товары» ожидается 17 карточек. Проверьте «Моторы» (5), «Аксессуары» (12) и напряжения 12/24/36 В.

В Creatium редактируемый текст меняется кликом по месту на странице, а загружаемая картинка — через её поле. Это штатный механизм `<cr-embed>`; он требует однократного создания каждого поля. В каталоге 146 полей: 128 текстовых, 17 картинок и один контейнер `cat_form`. [Документация Creatium по встраиваниям](https://creatium.academy/help/embed).

## Что менять в карточке

Например, мотор `M-P001-54` имеет поля `cat_m_p001_54_title`, `cat_m_p001_54_price`, `cat_m_p001_54_spec_1`…`_spec_4`, `cat_m_p001_54_label` и `cat_m_p001_54_image`. Такой же набор есть у каждого товара. Полный список с начальными значениями — `ВСТРАИВАНИЯ_КАТАЛОГ.csv`.

Фото моторов в папке `медиа/моторы-карточки/`. Их соответствие полям встраиваний указано в `ФОТО_МОТОРОВ.csv`. Пока фото не загружено в поле, HTML показывает прежний адрес картинки как запасной вариант.

Кнопка «Подробнее» использует ссылку в `href` соответствующей карточки. Creatium не позволяет изменить атрибут `href` через текстовое встраивание, поэтому **ссылки меняются во вкладке HTML**. Найдите карточку по `data-id="M-P001-54"` и измените `href` у её кнопки. При изменении категории или совместимости обновите и технические атрибуты карточки `data-type`, `data-voltage`, `data-compatible-voltage`, `data-compatibility`; фильтры читают именно их. Текст названия, цены, характеристик и изображение редактируются кликом.

## Поисковые системы

Названия, характеристики и ссылки на товары теперь находятся в HTML-разметке каталога, а JS лишь скрывает ненужные карточки после нажатия фильтра. Редактируемые тексты Creatium должны быть заполнены и сохранены перед публикацией. После публикации проверьте HTML опубликованной страницы и отрендеренную версию URL в инструментах поисковиков: конкретное поведение Creatium при выводе встраиваний нужно проверить на живом адресе.

Никакой синхронизации с таблицей у блока 04 больше нет. Блок 07 «Комплект» по-прежнему использует таблицу отдельно; если он не нужен, его можно не вставлять на страницу.
