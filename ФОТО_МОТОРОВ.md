# Изображения моторов для каталога

Пять новых изображений находятся в `медиа/моторы-карточки/`. Каждое имя файла совпадает с `data-id` моторной карточки в HTML-каталоге. Локальный `ПРЕДПРОСМОТР.html` уже использует их.

Чтобы показать их на странице Creatium, откройте вкладку «Встраивания» HTML-каталога и для пяти полей типа «Загружаемая картинка» выберите соответствующие PNG. Имена полей и файлов сопоставлены в `ФОТО_МОТОРОВ.csv`. База данных для каталога не нужна; исходные HTTPS-ссылки остались в `<img src>` как запасное изображение до загрузки нового.

Это сгенерированные изображения для дизайна карточек. Перед использованием как точного товарного фото проверьте детали корпуса, крепления и комплектацию по реальному товару.
