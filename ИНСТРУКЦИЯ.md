# HAIBO iPenguin — цветовой макет в Creatium

Это версия макета `превью/D-премиум-цветовой-макет.html`, разложенная на 13 HTML-компонентов. Тексты и фотографии меняются через вкладку «Встраивания». Каталог 04 теперь содержит все 17 товаров прямо в HTML и не требует подключения к базе данных. Блок 07 «Комплект» пока использует таблицу `HaiboProducts`. Штатные компоненты Creatium отвечают за видео и отправку форм.

## Что выяснено по Grok Build и документации Creatium

- В редакторе: HTML-секция → HTML-компонент → гаечный ключ → «Исходный код». Разметка, CSS и JS вставляются в разные вкладки, без `<style>` и `<script>`.
- `<cr-embed name="...">` связывает место в HTML с полем вкладки «Встраивания». Тип «Редактируемый текст» меняется кликом по странице; тип «Загружаемая картинка» задаёт фон элементу. У элемента картинки обязательно должна быть высота в CSS.
- Для кнопок с действиями и форм нужны контейнеры-встраивания. В них перетаскиваются штатные компоненты Creatium. Самодельные HTML-формы из прежнего превью заменены такими контейнерами: прежние формы только показывали `alert` и не отправляли заявку.
- Каталог 04 работает без таблицы: HTML содержит карточки, JS лишь переключает готовые карточки. Комплект 07 подключается к таблице через вкладку «Элемент» → «Включить подключение к таблицам»; строки доступны в JS как `data.rows`.
- Видео может не отображаться в монтажном редакторе; проверять его надо в «Предпросмотре». Адаптивные правила написаны через `.screen-md`, `.screen-sm`, `.screen-xs`.

Источники: [встраивания](https://creatium.academy/help/embed), [HTML](https://creatium.academy/help/components-html), [CSS](https://creatium.academy/help/components-css), [JS](https://creatium.academy/help/components-js), [подключение БД](https://creatium.academy/help/database-dev), [видео-уроки](https://creatium.academy/help/dev-video). Консольный чеклист Grok Build: `~/.grok/skills/creatium-blocks/SKILL.md`.

## Порядок вставки

### Исправление первого экрана (28.09.2026)

Для первого экрана замените содержимое вкладок **HTML и CSS** файлами `блоки/01_hero.html` и `блоки/01_hero.css`. Имена встраиваний остались прежними, введённые тексты и добавленный видео-компонент сохраняются. Подпись расположена под видео, а у контейнера `hero_video` нет `overflow:hidden` и перекрывающего слоя. Дополнительно убран лишний перенос `<br>` в H1, уменьшены вертикальные отступы и три преимущества выровнены в одну строку на широком экране. Текст `hero_video_title` и `hero_video_meta` выбирается кликом по подписи. Сам ролик меняется через штатный компонент «Видео» внутри встраивания `hero_video`: выберите его рамку/панель настроек, а не красную кнопку воспроизведения.

Чтобы все три преимущества помещались в одну строку без переноса слов, задайте короткие тексты во встраиваниях: `hero_fact_1` — «Дилер HAIBO в РФ», `hero_fact_2` — «Гарантия 2 года», `hero_fact_3` — «Помощь с подбором». На телефоне список выводится вертикально.

Если Creatium сообщает «Страница была изменена с момента последнего сохранения», сначала сохраните работу в активной вкладке и обновите вкладку, в которой вставляете код. Не подтверждайте перезапись другой открытой копии страницы.

### Медиа

В папке `медиа/` лежат 4 фотографии и 2 ролика. Загрузите фотографии в соответствующие поля `hero_photo`, `install_pvc_image`, `install_boat_image`, `cta_photo`. В контейнеры `hero_video` и `gps_video` перетащите штатный видео-компонент и укажите свои ролики либо поддерживаемые видео-ссылки. Видео следует проверять в «Предпросмотре».

Для пяти карточек моторов подготовлены отдельные изображения в `медиа/моторы-карточки/`. Их уже показывает локальный `ПРЕДПРОСМОТР.html`. В Creatium загрузите их в встраивания картинок каталога по [сопоставлению](ФОТО_МОТОРОВ.csv). Подробности — в [ФОТО_МОТОРОВ.md](ФОТО_МОТОРОВ.md).

Дополнительный раздел с 3D-видео, которое меняет кадр при прокрутке, готов в папке [дополнительный-блок-видео-скролл](дополнительный-блок-видео-скролл/ВСТАВКА.md). Для него также есть отдельные HTML, CSS и JS, редактируемые тексты и локальный предпросмотр. Его можно вставить вместо блока 03 «Технология».

Контейнеры `cat_form`, `combo_form`, `cta_form` предназначены для штатной кнопки или формы Creatium. Задайте реальные действия и поля формы в редакторе. В `combo_form` форма сама по себе не получает выбранные товары; в ней стоит добавить поле «Какой комплект выбрали?» или согласовать передачу выбора отдельно.

## Таблица для блока «Комплект»

В пакете есть `HaiboProducts_v2.csv`: 17 строк (5 моторов, 12 аксессуаров), исходные 59 полей и 2 новых поля:

- `combo_group`: `motor`, `battery`, `mount`, `protection`, `other`;
- `show_in_combo`: `1` или `0`.

Калькулятор учитывает совместимость серии и напряжения. Для P-003 не подставляет аккумулятор: в текущей таблице нет позиции на 36 В. Скидка по умолчанию **0%**; неподтверждённую скидку код не обещает.

Для каталога таблица не требуется. Следующие действия нужны только если вы используете блок 07 «Комплект».

Если таблица **ещё не создана**, импортируйте полный `HaiboProducts_v2.csv` в таблицу с точным именем `HaiboProducts`.

Если таблица **уже есть**, не импортируйте все 17 строк повторно: это создаст дубли. Добавьте в существующую таблицу два поля и заполните по `HaiboProducts_combo_обновить_поля.csv` по `id`. Пока поля не добавлены, калькулятор умеет определить группы по существующим полям и ID, чтобы страница не была пустой.

На блоке **07**: вкладка «Элемент» → включить подключение к таблицам → `HaiboProducts` → формат v0.2 → лимит 50 → выбрать нужные поля → «Применить». **Не выбирайте «Все поля»**: в таблице есть внутренние заметки `spec_conflict_note` и ссылки на источники, которые комплекту не нужны.

Для блока **07 Комплект** выберите: `id`, `active`, `sort_order`, `product_type`, `title`, `price`, `series`, `voltage_v`, `compatible_voltage`, `compatibility_filter`, `combo_group`, `show_in_combo`. Если два последних поля ещё не добавлены, код временно определит группы по ID существующих строк. Во вкладке «Настройки» добавьте число `combo_discount`, значение `0`, отметьте «Использовать в JS». Меняйте его только после утверждения реальной скидки.

Каталог не зависит от таблицы. Названия, цены, характеристики и фотографии меняются во встраиваниях HTML-компонента. Ссылки кнопок «Подробнее» и технические атрибуты фильтра меняются во вкладке HTML; подробности — в [инструкции по каталогу](КАТАЛОГ_БЕЗ_БД.md).

## Проверка после вставки

1. Дождитесь надписи «Сохранено» у каждого блока.
2. В «Предпросмотре» проверьте четыре ширины: широкий экран, ноутбук, планшет, телефон.
3. В каталоге ожидается «Показано 17 из 17 товаров» на вкладке «Все товары».
4. Проверьте фильтры 12/24/36 В и совместимость выбора в комплекте. Для P-003 аккумулятор должен остаться «Без аккумулятора».
5. Откройте обе видеовставки и отправьте тестовую заявку через штатную форму.
6. Проверьте фото, цены, ссылки на карточки и телефон.

Публикация тестовой страницы или замена боевой главной выполняется отдельно после проверки результата в редакторе.
