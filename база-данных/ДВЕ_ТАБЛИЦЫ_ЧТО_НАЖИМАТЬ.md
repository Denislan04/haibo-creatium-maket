# Два каталога HAIBO в Creatium

## Файлы и названия таблиц

| Название новой таблицы в Creatium | Файл для импорта | Товаров |
|---|---|---:|
| `HAIBO Электромоторы` | `HAIBO_ЭЛЕКТРОМОТОРЫ_5_Creatium.xlsx` | 5 |
| `HAIBO Аксессуары` | `HAIBO_АКСЕССУАРЫ_12_Creatium.xlsx` | 12 |

**Имя таблицы** ты задаёшь при создании. Внутренний цифровой ID таблицы Creatium присвоит сам; заранее его нет. Для подключения в редакторе выбирай таблицу по имени. Столбец `id` в файле — это **ID товара**, а не ID таблицы.

### ID товаров

**Электромоторы:** `M-P001-54`, `M-P001-72`, `M-P002-60`, `M-P002-72`, `M-P003-72`.

**Аксессуары:** `A-NAV-P65`, `A-QR-STANDARD`, `A-FUSE-60A`, `A-RAM-P65`, `A-BAT-24-100`, `A-BAT-12-100`, `A-COVER-54`, `A-COVER-72`, `A-BOW-PVC`, `A-CONNECTOR-50A`, `A-RAM-PVC-P65`, `A-QR-HD-P002-P003`.

## Как создать две таблицы

1. В личном кабинете сайта открой **«База данных» → «Создать таблицу»**.
2. Назови первую таблицу `HAIBO Электромоторы` и загрузи файл с пятью моторами. При сопоставлении колонок проверь типы из списка ниже.
3. Повтори для `HAIBO Аксессуары` и файла с 12 аксессуарами.
4. Открой обе таблицы в базе данных и проверь количество строк: **5** и **12**. Первые ID должны быть `M-P001-54` и `A-NAV-P65`.
5. Старую таблицу `Все товары новая` не удаляй, пока новая страница не проверена в предпросмотре.

Если Creatium предлагает выбрать источник данных, используй импорт локального **XLSX**. После импорта товары можно править прямо в строках БД Creatium.

## Какие типы указать для полей

| Поля | Тип | Что означает |
|---|---|---|
| `id`, `sku` | Текст | Постоянный ID и артикул. Не меняй `id` после настройки ссылок на товар. |
| `active`, `show_in_catalog` | Число | `1` = товар показываем, `0` = скрываем. |
| `sort_order` | Число | Порядок карточек по возрастанию. |
| `category`, `subcategory`, `title`, `short_description` | Текст | Категория, подкатегория, название, краткое описание. |
| `price`, `old_price` | Число | Рубли без «₽». Пустую `old_price` не показывай. |
| `image_url` | Картинка | Публичная прямая ссылка на фото. |
| `product_url` | Ссылка или Текст | Существующая страница товара. |
| `card_spec_1` … `card_spec_4` | Текст | Четыре короткие характеристики для видимой карточки. |

**Только у электромоторов:** `series`, `variant`, `propeller`, `mount`, `control`, `battery_recommend`, `kit_contents` — текст; `voltage_v`, `shaft_in`, `shaft_cm`, `boat_max_m`, `thrust_lbs`, `thrust_kg`, `motor_weight_kg`, `power_w`, `gps`, `glonass`, `beidou`, `compass` — число. Пустые характеристики не заполняй догадками.

**Только у аксессуаров:** `variant`, `compatible_voltage`, `compatibility_filter`, `compatibility_note`, `battery_type`, `dimensions`, `material`, `cycles`, `temp_range`, `peak_current_a` — текст; `voltage_v`, `capacity_ah`, `current_a`, `cable_length_m`, `charger_a`, `weight_kg` — число. `compatible_voltage` оставляй текстом: у совместимости могут быть несколько значений.

## Как вывести обе таблицы на странице

Для двух источников нужны **две секции с блоками**: первая выводит моторы, вторая — аксессуары.

1. В первой секции открой **«Настройки секции» → «Данные»**, выбери `HAIBO Электромоторы`, открой «Запрос». Поставь **Количество записей: 20** и сортировку по `sort_order` по возрастанию. Нажми **«Применить»**. Во вкладке результата должно быть **5**.
2. Оставь в этой секции одну карточку как образец. Всё, что привязываешь в ней, Creatium повторит для остальных строк таблицы.
3. Дублируй секцию для аксессуаров, во второй секции выбери `HAIBO Аксессуары` и нажми «Применить». Результат должен быть **12**. Проверь привязки переменных после смены источника.
4. Сохрани страницу и проверь предпросмотр.

### Что выбрать в окне «Источник данных / Переменная» на твоём скриншоте

В выпадающем списке сверху должна быть **таблица соответствующей секции**. В списке переменных выбирай:

| Элемент карточки | Переменная |
|---|---|
| Название | `title` |
| Подпись «Электромоторы» / «Аксессуары» | `category` |
| Описание под названием | `short_description` |
| Текст, где сейчас написано `medium` или `conflict` | `card_spec_1` или удалить этот текстовый элемент |
| Остальные краткие свойства | `card_spec_2`, `card_spec_3`, `card_spec_4` |
| Основная цена | `price` |
| Перечёркнутая старая цена | `old_price` |
| Картинка | `image_url` в настройках картинки, источник — таблица |
| Кнопка «Подробнее» | `product_url` |

На скриншоте `medium`/`conflict` взяты из старого служебного поля `data_confidence`; покупателю его показывать не нужно. Надписи **«от 24 490 руб.»** тоже являются текстом шаблона: заменяй их на `price`/`old_price`, не оставляя «от», если цена у конкретного товара фиксированная.

Для кнопки **«Купить»** включи у блока режим **«Карточка товара»** и проверь настройки передачи в корзину: название `title`, цена `price`, фото `image_url`. Вторая цена должна быть скрыта, если `old_price` пустая.

## Проверка перед публикацией

- У первого мотора должно быть название `HAIBO P001 iPenguin 12V 54″`, цена `132900`, а не `24 490`.
- У первого аксессуара должно быть название `HAIBO NAV SENSOR — компас / курсоуказатель`, цена `10900`.
- В списках 5 и 12 товаров, каждая карточка со своим фото и описанием.
- Цены в файлах перенесены из прежнего каталога; перед публикацией сверь их с актуальными ценами магазина.
