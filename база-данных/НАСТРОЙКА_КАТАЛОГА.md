# Каталог HAIBO в штатных карточках Creatium

## Что уже есть

- В исходной таблице 17 товаров: 5 моторов и 12 аксессуаров.
- На странице «тест главной» в настройках подключённой таблицы «Все товары новая» было указано **Количество записей: 10**. После установки 50 запрос показал **Результат (17)**. Значит, семь товаров не потерялись: их скрывал лимит вывода.
- У текущего шаблона карточки название уже берётся из `title`. Описание, цена, старая цена и картинка ещё остались от демонстрационного iPhone и требуют привязки.

## Как закончить текущий каталог без повторного импорта

1. В редакторе открой секцию каталога **«Секция с блоками» → «Настройки секции» → «Данные» → «Запрос»**.
2. В поле **«Количество записей»** укажи `50`. Проверь вкладку **«Результат (17)»**, затем нажми **«Применить»** и сохрани страницу. Если редактор показывает «Не сохранено», изменение ещё не сохранено окончательно.
3. Выдели **первую карточку** внутри подключённой секции. Настраивается образец карточки; изменения повторятся для остальных товаров.
4. Вместо демонстрационных данных привяжи элементы к столбцам таблицы:

   | Элемент карточки | Столбец |
   |---|---|
   | Название | `title` |
   | Краткое описание | `short_description` |
   | Цена | `price` |
   | Перечёркнутая цена | `old_price` |
   | Фото | `image_url` |
   | Категория/метка | `subcategory` |
   | До четырёх кратких свойств | `card_spec_1` … `card_spec_4` |
   | Ссылка «Подробнее» | `product_url` |

5. Для текста выдели его и используй **«Переменная» / `{x}`**. Для фотографии открой настройки картинки и выбери источником столбец `image_url` таблицы. У столбца должен быть тип **«Картинка»**. В редакторе 4.2, который открыт сейчас, доступна привязка через источник таблицы.
6. Для пустого `old_price` задай условие видимости: показывать элемент только при заполненном значении. У большинства аксессуаров старая цена отсутствует.
7. У блока включи **«Карточка товара»** и отдельно сопоставь поля корзины: название = `title`, цена = `price`, фото = `image_url`. Проверь добавление мотора и аксессуара в корзину на предпросмотре.

**Не импортируй исходные 17 строк ещё раз в «Все товары новая»:** товары там уже есть, повторный импорт может создать дубли.

## Чистая таблица для нового каталога

Файл `HAIBO_каталог_17_товаров_Creatium.xlsx` содержит те же 17 товаров в одном листе «Каталог», но только 35 полей, нужных для каталога, фильтрации и основных характеристик. Моторы и аксессуары находятся в **одной таблице**; поля, неприменимые к конкретному типу товара, оставлены пустыми.

Если захочешь заменить старую структуру, создай **новую** таблицу в разделе **«База данных» → «Создать таблицу»**, загрузи XLSX и назови её, например, «HAIBO каталог 17». Затем в секции каталога выбери эту таблицу, нажми «Применить» и заново проверь привязки карточки. Старую таблицу сохраняй до проверки новой.

### Поля и типы

| Группа | Поля | Тип в Creatium / назначение |
|---|---|---|
| Идентификаторы | `id`, `sku` | Текст. `id` — постоянный уникальный ключ товара, `sku` — артикул. |
| Управление | `active`, `show_in_catalog`, `public_card`, `show_in_combo` | Число 1/0. В каталоге показывать записи с `active=1` и `show_in_catalog=1`. |
| Порядок | `sort_order` | Число. Сортировка по возрастанию. |
| Разделы | `product_type`, `category`, `subcategory`, `combo_group` | Текст. `product_type`: `motor` или `accessory`. Для кнопок «Моторы/Аксессуары» фильтровать по нему. |
| Карточка | `title`, `short_description`, `card_spec_1` … `card_spec_4` | Текст. Эти поля подходят для обоих типов товара. |
| Цена | `price`, `old_price` | Число без символа ₽. `old_price` может быть пустым. |
| Изображение и ссылка | `image_url`, `product_url` | `image_url` — Картинка, `product_url` — Ссылка или Текст. |
| Мотор | `series`, `variant`, `voltage_v`, `shaft_cm`, `boat_max_m`, `thrust_kg`, `power_w` | `series` и `variant` — Текст; остальные — Число. Пустые значения означают, что характеристика не подтверждена или неприменима. |
| Аксессуар и совместимость | `compatible_voltage`, `compatibility_filter`, `compatibility_note`, `capacity_ah`, `battery_type`, `current_a`, `material` | `compatible_voltage`, фильтр, пояснение, тип батареи и материал — Текст; ёмкость и ток — Число. Не расширяй совместимость аксессуара автоматически на все моторы. |

Для первой версии фильтра достаточно `product_type`, `subcategory` и диапазона `price`. Фильтр 12/24/36 В по `voltage_v` применяй к моторам: совместимость аксессуаров хранится отдельно и не всегда сводится к одному числу.

Текущие изображения в файле — публичные URL из прежней таблицы. Чтобы поставить сгенерированные фотографии моторов, сначала загрузи файлы в Creatium и замени URL в поле `image_url` у пяти моторных строк.

## Проверка

После настройки проверь три записи: мотор `M-P001-54`, аккумулятор `A-BAT-24-100` и аксессуар `A-NAV-P65`. У каждой должны появиться свои название, описание, цена и фото. В каталоге должно быть 17 товаров, а не 10.
